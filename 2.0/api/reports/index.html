    Reports, workflow and cache

    evalsuite.auto_report

    One call (or one command) from a table of predictions to a full HTML evaluation report.

    import evalsuite as es es.auto_report("predictions.csv") # works out the columns and the task es.auto_report(df, target="label", prob="risk", groups=["sex"], path="report.html")

    From the shell: evalsuite report predictions.csv writes report.html next to the data.

    Columns are recognised by name (case-insensitive): the outcome (y_true, label, target, outcome, truth, actual, y), predicted labels or values (y_pred, pred, prediction, predicted), predicted probabilities (y_prob, prob, proba, probability, risk, score, or one prob_<class> column per class), subgroups (sex, gender, age_group, race, ethnicity, site, group) and clusters (patient_id, subject_id, cluster). Anything detected wrongly can be given explicitly. The task follows from the outcome: two classes → binary (discrimination, calibration, TRIPOD+AI card, fairness when groups exist), more classes → multiclass, otherwise regression.

    AutoReport dataclass

    The detected set-up, the results that went into the report, and the report's HTML.

    detect_columns(columns: Sequence[str]) -> dict[str, Any]

    Guess which column plays which role (see the module docstring).

    auto_report 

    auto_report(data: Any, *, target: Optional[str] = None, pred: Optional[str] = None, prob: Union[str, Sequence[str], None] = None, groups: Optional[Sequence[str]] = None, clusters: Optional[str] = None, task: Optional[str] = None, threshold: float = 0.5, path: Optional[str] = None, title: Optional[str] = None, random_state: Optional[int] = 0) -> AutoReport

    Detect the columns and task (see the module docstring), evaluate, and build one HTML report. With a file path as data, the report is written next to it as <name>.report.html unless path is given.

    evalsuite.html_report

    One self-contained HTML file for a whole evaluation: tables, intervals, plots and narrative, to attach to a paper, a pull request or an e-mail.

    page = es.html_report( ... {"Test set": result, "Leaderboard": board, "Fairness": fairness, "Calibration": es.plot.calibration(...)}, ... title="Sepsis model v3 evaluation", path="report.html", ... )

    Each section can be any EvalSuite result (evaluate, compare, leaderboard, report_card, fairness_report, judge_report, rag_report, sample-size plans, metric results), a Matplotlib figure (embedded as a PNG), or text (paragraphs; Markdown tables are rendered as tables). The file has inline CSS, no scripts and no external requests, so it opens anywhere and is safe to share; all text is escaped.

    html_report 

    html_report(sections: Union[Mapping[str, Any], Sequence[Any]], *, title: str = 'Evaluation report', intro: Optional[str] = None, path: Optional[str] = None, metadata: Optional[Mapping[str, Any]] = None) -> str

    Build the report and return the HTML (also written to path when given). sections maps headings to content, or is a list (headings are then taken from each result's kind). intro is Markdown text placed under the title; metadata adds rows to the provenance footer (data set, model version, ...).

    evalsuite.workflow

    Workflow integrations: log results to MLflow or Weights & Biases, keep a history of evaluations and flag regressions, and serve EvalSuite over HTTP.

    import evalsuite as es es.log_to_mlflow(result) # inside an active MLflow run (or pass run_id=) es.log_to_wandb(result) # inside wandb.init() es.record_history(result, model="v3", dataset="test-2024") # appends to .evalsuite/history.jsonl es.check_regression(result, model="v3", dataset="test-2024") # against the latest recorded result

    shell: evalsuite history list | evalsuite serve --port 8000

    Logging writes each metric's value and interval bounds as scalar metrics (accuracy, accuracy_ci_low, …), the full result as JSON, and its HTML table, so dashboards show intervals rather than bare numbers. The history is a plain JSON-lines file (one evaluation per line) that can live in the repository next to the code.

    metrics_dict 

    metrics_dict(result: Any, *, prefix: str = '') -> dict[str, float]

    Flat {name: value, name_ci_low: …, name_ci_high: …} of an EvalSuite result (evaluation, metric, report with metrics); non-finite values are left out.

    log_to_mlflow 

    log_to_mlflow(result: Any, *, prefix: str = '', run_id: Optional[str] = None, artifact: str = 'evalsuite') -> dict[str, float]

    Log a result to MLflow: scalar metrics (with interval bounds), <artifact>.json and <artifact>.html. Uses the active run, or run_id. Returns the logged metrics.

    log_to_wandb 

    log_to_wandb(result: Any, *, prefix: str = '', table: str = 'evalsuite') -> dict[str, float]

    Log a result to the active Weights & Biases run: scalar metrics (with interval bounds) and a table of the metrics. Returns the logged metrics.

    record_history 

    record_history(result: Any, *, model: str, dataset: str = 'default', path: Optional[str] = None, note: Optional[str] = None) -> dict[str, Any]

    Append one evaluation (model version, data set, timestamp, metrics with intervals) to the history file (.evalsuite/history.jsonl by default, or $EVALSUITE_HISTORY).

    load_history 

    load_history(*, model: Optional[str] = None, dataset: Optional[str] = None, path: Optional[str] = None) -> list[dict[str, Any]]

    Recorded evaluations, oldest first, optionally for one model and / or data set.

    check_regression 

    check_regression(result: Any, *, model: Optional[str] = None, dataset: str = 'default', baseline: Optional[Mapping[str, Any]] = None, path: Optional[str] = None, tolerance: float = 0.0) -> dict[str, Any]

    Compare result with the latest recorded evaluation of model (any model when None) on dataset, or with baseline (a history entry). A metric regressed when it got worse by more than tolerance and the new confidence interval lies entirely on the worse side of the old estimate. Returns {"regressed": [...], "improved": [...], "baseline": entry}.

    serve 

    serve(host: str = '127.0.0.1', port: int = 8000) -> None

    A small JSON HTTP service (standard library only): GET /health, GET /metrics (the catalogue) and POST /evaluate with {"y_true": [...], "y_pred": [...], "y_prob": [...], ...} (any :func:evalsuite.evaluate keyword) returning the result as JSON. Binds to localhost by default.

    evalsuite.dataframe

    df.evalsuite on pandas and Polars DataFrames.

    import evalsuite as es es.register_accessors() # once; or: import evalsuite.dataframe df.evalsuite.evaluate("label", "pred", y_prob="risk") df.evalsuite.compare("label", {"lr": "pred_lr", "rf": "pred_rf"}) df.evalsuite.report() # automatic HTML report train.evalsuite.drift(test); test.evalsuite.card(target="label"); train.evalsuite.leakage(test)

    Column arguments are column names. Registration is explicit (importing EvalSuite never imports pandas or Polars); importing this module registers the accessor for whichever of the two is installed.

    evalsuite.cache

    EvalSuite's cache folder: where downloaded benchmark data and the update-check record live.

    import evalsuite as es es.cache_info() # location, size, entries es.clear_cache(older_than="30d") # or clear_cache() for everything

    The folder is $EVALSUITE_CACHE if set, else $XDG_CACHE_HOME/evalsuite, %LOCALAPPDATA%\evalsuite on Windows, or ~/.cache/evalsuite. From the command line: evalsuite cache info and evalsuite cache clear.

    Automatic clearing: at most once a day, in the background after import, entries not used for EVALSUITE_CACHE_MAX_AGE (default 90 days) are removed, then the least recently used entries until the cache is below EVALSUITE_CACHE_MAX_SIZE (default 2 GB). Set EVALSUITE_CACHE_AUTO_CLEAN=0 to turn it off. Only folders EvalSuite created (they carry a marker file) are ever touched, and only whole entries (one data set download, one record) are removed, never part of one.

    CacheInfo dataclass

    What the cache holds.

    cache_dir 

    cache_dir(*, create: bool = False) -> Path

    The cache folder (see the module docstring); create=True makes it, with its marker file.

    cache_info 

    cache_info() -> CacheInfo

    Location, size and entries of the cache, and the automatic-clearing settings.

    clear_cache 

    clear_cache(*, older_than: Union[str, float, None] = None, max_size: Union[str, int, None] = None, dry_run: bool = False) -> dict[str, Any]

    Delete cache entries: everything, or those unused for older_than (e.g. "30d"), then the least recently used until the cache is below max_size (e.g. "1GB"). Returns what was (or with dry_run=True would be) removed. Only a folder EvalSuite created is touched.

    auto_clean 

    auto_clean(*, force: bool = False) -> Optional[dict[str, Any]]

    The automatic clearing (see the module docstring): runs at most once a day unless force; never raises.
