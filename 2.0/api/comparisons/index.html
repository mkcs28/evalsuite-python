    Comparisons, agreement and Bayesian

    evalsuite.comparisons

    Comparisons beyond "is there a difference": equivalence and non-inferiority, many models over many data sets, and metrics when some labels are missing.

    import evalsuite as es es.noninferiority_test("accuracy", y, pred_new, pred_old, margin=0.02) # is the new model no worse? es.equivalence_test("roc_auc", y, y_prob_a=pa, y_prob_b=pb, margin=0.01) # practically the same (TOST)? nem = es.nemenyi_test(scores) # datasets × models → average ranks, critical difference, pairwise p es.plot.critical_difference(nem) # the critical-difference diagram (Demšar 2006) es.ipw_metric("accuracy", y, pred, observed=has_label, p_observed=propensity)

    Non-inferiority and equivalence follow the FDA / EMA two one-sided tests (TOST, Schuirmann 1987) on the paired bootstrap distribution of metric(A) − metric(B): non-inferior when the lower (1 − 2α) bound exceeds −margin; equivalent when the whole (1 − 2α) interval lies inside ±margin. The Nemenyi test (Nemenyi 1963; Demšar, JMLR 2006) compares every pair of models by average rank across data sets after a Friedman test. ipw_metric weights labelled examples by the inverse probability of having a label (Horvitz–Thompson), which removes the bias of evaluating only on cases that happened to be labelled when labelling depends on observed covariates.

    NemenyiResult dataclass

    Friedman test, average ranks, critical difference and pairwise Nemenyi p-values.

    noninferiority_test 

    noninferiority_test(metric: Any, y_true: Any, y_pred_a: Any = None, y_pred_b: Any = None, *, margin: float, alpha: float = 0.025, y_prob_a: Any = None, y_prob_b: Any = None, sample_weight: Any = None, higher_is_better: Optional[bool] = None, n_resamples: int = 2000, random_state: Optional[int] = None, stratify: Optional[bool] = None, **metric_kwargs: Any) -> TestResult

    Is model A (new) no worse than model B (reference) by more than margin? One-sided test at alpha (0.025 by default, as regulators expect) on paired bootstrap differences; params["conclusion"] is True when the lower (1 − 2α) confidence bound of A − B (oriented so higher is better) is above −margin.

    equivalence_test 

    equivalence_test(metric: Any, y_true: Any, y_pred_a: Any = None, y_pred_b: Any = None, *, margin: float, alpha: float = 0.05, y_prob_a: Any = None, y_prob_b: Any = None, sample_weight: Any = None, n_resamples: int = 2000, random_state: Optional[int] = None, stratify: Optional[bool] = None, **metric_kwargs: Any) -> TestResult

    Are models A and B equivalent within ±margin? Two one-sided tests (TOST) at alpha on paired bootstrap differences; params["conclusion"] is True when the (1 − 2α) interval of A − B lies inside ±margin.

    nemenyi_test 

    nemenyi_test(scores: Any, *, models: Optional[list[str]] = None, alpha: float = 0.05, higher_is_better: bool = True) -> NemenyiResult

    Compare k models over N data sets (or folds): scores is N × k (a DataFrame's columns name the models), or a mapping model → N scores. Ranks are computed per data set (ties share the average rank; 1 = best).

    ipw_metric 

    ipw_metric(metric: Any, y_true: Any, y_pred: Any = None, *, observed: Any, p_observed: Any, y_prob: Any = None, clip: Union[float, tuple[float, float]] = 0.01, **metric_kwargs: Any) -> MetricResult

    A metric over the whole population when only some examples are labelled: labelled examples (observed True) are weighted by 1 / p_observed (their estimated probability of being labelled, e.g. from a logistic model of labelling on covariates). Propensities are clipped to [clip, 1] to limit extreme weights. params reports the effective sample size and the unweighted (complete-case) value for comparison.

    evalsuite.agreement

    Agreement studies: how well raters, instruments or methods agree on the same subjects.

    import evalsuite as es icc = es.icc(ratings) # subjects × raters matrix → all six ICC forms with CIs icc["ICC2"].value, icc["ICC2"].low, icc["ICC2"].high ba = es.bland_altman(method_a, method_b) # bias, limits of agreement (with CIs), proportional bias ccc = es.lins_ccc(method_a, method_b) # Lin's concordance correlation with a CI

    ICC forms follow Shrout & Fleiss (1979) and McGraw & Wong (1996), with the exact F-based confidence intervals (ICC2 by Satterthwaite's approximation), as in pingouin and R's psych::ICC. Bland–Altman limits use the Bland & Altman (1999) standard errors; Lin's CCC uses the Fisher-z interval of Lin (1989).

    ICCForm dataclass

    One intraclass correlation: estimate, F test against zero and confidence interval.

    ICCResult dataclass

    All six ICC forms for a subjects × raters table. Index by form name (result["ICC2"]).

    to_html 

    to_html(*, digits: int = 3) -> str

    The Markdown tables as an HTML fragment (escaped), e.g. for :func:evalsuite.html_report.

    BlandAltman dataclass

    Bland–Altman analysis of two measurement methods on the same subjects.

    to_html 

    to_html(*, digits: int = 3) -> str

    The Markdown tables as an HTML fragment (escaped), e.g. for :func:evalsuite.html_report.

    plot 

    plot(ax: Any = None) -> Any

    Difference against mean with bias and limits of agreement (Matplotlib).

    icc 

    icc(ratings: Any, *, subjects: Any = None, raters: Any = None, level: float = 0.95, missing: str = 'drop') -> ICCResult

    Intraclass correlation coefficients (all six Shrout–Fleiss forms) with F tests and confidence intervals.

    ratings is a subjects × raters table, or one rating per row with subjects= and raters= (long format). Subjects with a missing rating are dropped (missing="drop") or rejected (missing="raise"). Choose the form by design: ICC2 / ICC2k when the raters are a sample of possible raters and absolute agreement matters, ICC3 / ICC3k for these fixed raters' consistency, ICC1 when each subject has different raters; "k" forms describe the mean of the k ratings.

    bland_altman 

    bland_altman(method_a: Any, method_b: Any, *, level: float = 0.95, loa_level: float = 0.95) -> BlandAltman

    Bias and limits of agreement between two methods (Bland & Altman 1986), with confidence intervals for the bias (t) and for each limit (Bland & Altman 1999), and a test for proportional bias (regression of the difference on the mean).

    lins_ccc 

    lins_ccc(method_a: Any, method_b: Any, *, level: float = 0.95) -> Any

    Lin's concordance correlation coefficient (agreement with the identity line) with the Fisher-z confidence interval of Lin (1989); returns a :class:~evalsuite.MetricResult.

    evalsuite.bayes

    Bayesian comparison of two models: the probability that one is better, not a p-value.

    import evalsuite as es b = es.bayes_compare(y_true, pred_a, pred_b, metric="accuracy", rope=0.01) b.p_a_better, b.p_rope, b.p_b_better # probabilities that sum to 1 b.summary() # "A is better with probability 0.97 ..." es.bayes_correlated_ttest(cv_scores_a, cv_scores_b, test_fraction=0.2, rope=0.01)

    bayes_compare puts a Bayesian bootstrap (Rubin 1981: flat Dirichlet weights over the test examples) on the paired test set and returns the posterior of the metric difference, its credible interval and the probabilities of A better, practically equivalent (inside the region of practical equivalence, ROPE) and B better. bayes_correlated_ttest is the correlated Bayesian t-test of Benavoli et al. (2017) for scores from k-fold cross-validation, where training sets overlap.

    BayesComparison dataclass

    Posterior of metric(A) − metric(B) and the decision probabilities.

    samples property 

    samples: ndarray

    Posterior draws of the difference (drawn on first access for the t-test, whose probabilities are exact).

    p_rope_or_better property 

    p_rope_or_better: float

    Probability that A is not practically worse than B (non-inferiority).

    decision 

    decision(*, threshold: float = 0.95) -> str

    "A better", "B better", "equivalent" or "undecided" at a posterior probability.

    to_html 

    to_html(*, digits: int = 3) -> str

    The Markdown tables as an HTML fragment (escaped), e.g. for :func:evalsuite.html_report.

    bayes_compare 

    bayes_compare(y_true: Any, pred_a: Any, pred_b: Any, *, metric: Union[str, Callable[..., Any]] = 'accuracy', rope: Union[float, tuple[float, float]] = 0.01, level: float = 0.95, n_samples: int = 4000, higher_is_better: Optional[bool] = None, random_state: Optional[int] = None, **metric_kwargs: Any) -> BayesComparison

    Posterior of the difference in metric between two models scored on the same examples.

    Each posterior draw weights the test examples by flat Dirichlet weights (Bayesian bootstrap) and evaluates the metric on both models with those weights, so the pairing is kept. pred_a / pred_b are labels, or scores for probability metrics (metric="roc_auc", "brier"...). rope is the region of practical equivalence on the metric's scale (±0.01 by default).

    bayes_correlated_ttest 

    bayes_correlated_ttest(scores_a: Any, scores_b: Any, *, test_fraction: Optional[float] = None, rope: Union[float, tuple[float, float]] = 0.01, level: float = 0.95, higher_is_better: bool = True, n_samples: int = 50000, random_state: Optional[int] = None, metric: str = 'score') -> BayesComparison

    Correlated Bayesian t-test (Benavoli, Corani, Demšar & Zaffalon 2017) for per-fold cross-validation scores of two models on the same folds. test_fraction is n_test / n_total of a fold (1/k for k-fold; the default), which sets the correlation between folds (Nadeau & Bengio 2003). The posterior of the mean difference is a Student t with n − 1 degrees of freedom; probabilities are exact and the draws only feed samples.
