    Calibration and recalibration

    evalsuite.calibration

    Calibration of predicted probabilities: maximum calibration error, calibration slope and intercept (logistic recalibration) and the Hosmer–Lemeshow goodness-of-fit test.

    The calibration curve, expected calibration error and Brier score live in :mod:evalsuite.classification and are re-exported here for convenience.

    CalibrationReport dataclass

    Calibration of one model's predicted risks: Brier score, ECE, MCE, intercept, slope and Hosmer–Lemeshow, plus the binned calibration curve (curve: prob_true, prob_pred, bin_weight).

    calibration_curve 

    calibration_curve(y_true: ArrayLike, y_prob: ArrayLike, *, n_bins: int = 10, strategy: Literal['uniform', 'quantile'] = 'uniform', pos_label: Any = None, sample_weight: Optional[ArrayLike] = None) -> tuple[FloatArray, FloatArray, FloatArray]

    Reliability diagram data for binary probabilities: (prob_true, prob_pred, bin_weight) per non-empty bin, where prob_true is the observed positive rate and prob_pred the mean predicted probability.

    strategy="uniform" uses equal-width bins on [0, 1]; "quantile" uses equal-count bins. Matches scikit-learn's calibration_curve (unweighted), and also accepts sample weights.

    Weighted maximum-likelihood logistic regression by Newton–Raphson.

    offset=True fits logit P(y=1) = a + x (returns [a]); otherwise logit P(y=1) = a + b·x (returns [a, b]).

    hosmer_lemeshow 

    hosmer_lemeshow(y_true: ArrayLike, y_prob: ArrayLike, *, n_groups: int = 10, pos_label: Any = None) -> TestResult

    Hosmer–Lemeshow goodness-of-fit test for predicted risks.

    Observations are sorted by predicted risk and split into n_groups groups of (nearly) equal size ("deciles of risk"). The statistic Σ (O − E)² / (E (1 − E/nₖ)) is compared with χ² on n_groups − 2 degrees of freedom (use n_groups degrees of freedom for an external validation set by reading params["statistic"]). A large p-value does not show that calibration is good, especially in small samples; report the calibration curve, slope and intercept as well.

    calibration_report 

    calibration_report(y_true: ArrayLike, y_prob: ArrayLike, *, n_bins: int = 10, strategy: Literal['uniform', 'quantile'] = 'uniform', n_groups: int = 10, pos_label: Any = None, n_resamples: Optional[int] = None, level: float = 0.95, random_state: Optional[int] = None) -> CalibrationReport

    Every calibration measure for binary predicted risks in one object (see :class:CalibrationReport).

    With n_resamples (e.g. 1000), percentile bootstrap confidence intervals are added for the Brier score, ECE, MCE, calibration intercept and slope (report.intervals).

    evalsuite.recalibration

    Recalibration: fit a map from a model's probabilities to calibrated ones on held-out data, then apply it.

    import evalsuite as es cal = es.recalibrate(y_val, p_val, method="isotonic") # "platt", "temperature", "beta", "histogram" p_test_cal = cal(p_test) # or cal.transform(p_test) es.calibration_report(y_test, p_test_cal, n_resamples=1000) # check it on separate data, with CIs

    Methods: Platt scaling (Platt 1999, with Platt's smoothed targets, on the logit of the probabilities), isotonic regression (Zadrozny & Elkan 2002; pool-adjacent-violators, clipped outside the fitted range), temperature scaling (Guo et al. 2017; one parameter, also for multiclass probability matrices), beta calibration (Kull, Silva Filho & Flach 2017; three parameters) and histogram binning (equal-mass bins). Fit on data the model was not trained on, and evaluate on different data again.

    Calibrator dataclass

    A fitted recalibration map. Call it (or transform) on new probabilities.

    recalibrate 

    recalibrate(y_true: Any, y_prob: Any, *, method: str = 'isotonic', n_bins: int = 10, pos_label: Any = None, sample_weight: Any = None, classes: Any = None) -> Calibrator

    Fit a recalibration map on held-out labels and probabilities (see the module docstring for methods).

    For method="temperature" y_prob may be an n × k probability matrix: integer labels index the columns, other labels map to the sorted labels unless classes= gives the label of each column.

    evalsuite.conformal

    Conformal prediction: prediction sets and intervals with a finite-sample coverage guarantee.

    import evalsuite as es sets = es.conformal_classification(y_cal, p_cal, p_test, alpha=0.1) # 90% prediction sets sets.sets[0], sets.mean_size es.conformal_classification(y_cal, p_cal, p_test, y_test=y_test).coverage # check on labelled data iv = es.conformal_regression(y_cal, yhat_cal, yhat_test, alpha=0.1) # 90% intervals iv.lower, iv.upper

    Split conformal prediction (Vovk et al. 2005; Lei et al. 2018; Angelopoulos & Bates 2023): a held-out calibration set gives the score threshold q̂ = the ⌈(n + 1)(1 − α)⌉-th smallest calibration score, and for a new exchangeable example P(y ∈ set) ≥ 1 − α, whatever the model. Classification scores: "lac" (1 − probability of the true class; smallest sets), "aps" (adaptive prediction sets, Romano et al. 2020; sets that grow with uncertainty) and "raps" (regularised APS, Angelopoulos et al. 2021). Regression: "absolute" residuals, "normalized" residuals divided by a per-example scale (e.g. a predicted SD) and "cqr" (conformalized quantile regression, Romano et al. 2019) from lower / upper quantile predictions. by= gives Mondrian (group-conditional) conformal prediction: a threshold per group, so coverage holds within every group (classes, sites, subgroups).

    With labelled test data, the result reports empirical coverage with a Wilson interval, the coverage per group and per set size, and set sizes / interval widths — the checks reviewers ask for.

    conformal_classification 

    conformal_classification(y_cal: Any, p_cal: Any, p_test: Any, *, alpha: float = 0.1, method: str = 'aps', y_test: Any = None, classes: Any = None, by: Any = None, by_test: Any = None, lam: float = 0.01, k_reg: int = 1, level: float = 0.95) -> ConformalSets

    Split-conformal prediction sets from class probabilities (see the module docstring).

    y_cal / p_cal are held-out calibration labels and probabilities (n × k); p_test the probabilities to build sets for. by / by_test (or by="class") give group-conditional thresholds. With y_test the result also reports coverage overall, per group and per set size.

    conformal_regression 

    conformal_regression(y_cal: Any, pred_cal: Any, pred_test: Any, *, alpha: float = 0.1, method: str = 'absolute', scale_cal: Any = None, scale_test: Any = None, y_test: Any = None, by: Any = None, by_test: Any = None, level: float = 0.95) -> ConformalIntervals

    Split-conformal prediction intervals (see the module docstring).

    "absolute": pred_* are point predictions; interval pred ± q̂. "normalized": also give scale_cal / scale_test (positive per-example scales such as predicted SDs); interval pred ± q̂·scale. "cqr": pred_* are n × 2 arrays of lower and upper quantile predictions (e.g. the α/2 and 1 − α/2 quantiles); interval [lo − q̂, hi + q̂]. by / by_test give a threshold per group.
