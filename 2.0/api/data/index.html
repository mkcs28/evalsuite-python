    Data quality, drift and forecasting

    evalsuite.data_quality

    Data quality before evaluation: leakage between splits, likely label errors, and a summary card of a data set.

    import evalsuite as es es.leakage_report(train_df, test_df, target="label", id_column="patient_id") es.label_issues(y, pred_probs) # likely mislabelled examples (confident learning) es.dataset_card(test_df, target="label", groups=["sex", "site"])

    leakage_report finds test rows that also appear in training (exact duplicates after normalising numbers and text), near-duplicates (numeric rows within near_tol standardised units of a training row; texts whose word-shingle Jaccard similarity is at least text_threshold, found with MinHash), shared identifiers (the same patient or document in both splits) and features that predict the target almost perfectly (a sign that the answer leaked into the inputs). label_issues implements confident learning (Northcutt, Jiang & Chuang 2021): an example is flagged when its out-of-sample probability for another class clears that class's average self-confidence threshold. dataset_card summarises size, missing values, class balance, feature types, subgroup counts and duplicates.

    LeakageReport dataclass

    Overlap between a training and a test set. findings lists each check with the affected test rows.

    leaked_rows property 

    leaked_rows: list[int]

    Test rows affected by any duplicate or shared-identifier finding (sorted).

    LabelIssues dataclass

    Examples whose given label looks wrong, ranked by how unlikely the label is under the model.

    DatasetCard dataclass

    A summary of a data set for a paper's methods section or a model card.

    leakage_report 

    leakage_report(train: Any, test: Any, *, target: Optional[str] = None, id_column: Optional[str] = None, text_columns: Optional[Sequence[str]] = None, columns: Optional[Sequence[str]] = None, near_tol: float = 0.001, text_threshold: float = 0.8, shingle: int = 3, target_auc: float = 0.99) -> LeakageReport

    Check a train / test split for leakage (see the module docstring). columns restricts the feature columns compared (default: all shared columns except target and id_column).

    label_issues 

    label_issues(y: Any, pred_probs: Any, *, classes: Any = None) -> LabelIssues

    Likely label errors by confident learning (Northcutt et al. 2021). pred_probs must be out-of-sample (e.g. cross-validated) class probabilities, n × k; columns are integer labels, or classes= gives the label of each column. Returned examples are sorted from the most to the least suspicious.

    dataset_card 

    dataset_card(data: Any, *, target: Optional[str] = None, groups: Optional[Sequence[str]] = None) -> DatasetCard

    Size, column types, missing values, numeric summaries, class balance of target, counts per subgroup (groups) and duplicate rows.

    evalsuite.drift

    Data drift between a reference set (training or validation data) and current data, feature by feature.

    import evalsuite as es rep = es.drift_report(train_df, live_df) # DataFrames, dicts of columns or 2-D arrays rep.drifted() # features that changed significantly and materially print(rep.summary()); rep.to_html()

    Numeric features: two-sample Kolmogorov–Smirnov test, population stability index (PSI, reference-quantile bins) and Wasserstein distance in reference standard deviations. Categorical features (strings, booleans, or categorical=[...]): chi-square test of homogeneity, PSI over categories and Jensen–Shannon distance. Missing-value rates are compared with a two-proportion z-test. P-values are Holm-adjusted across features. A feature is flagged when its adjusted p-value is below alpha and the shift is material (PSI ≥ psi_threshold or distance ≥ distance_threshold: 0.1 reference SDs, or a Jensen–Shannon distance of 0.1), so a large data set does not flag trivial shifts; a significant change of at least one point in the missing-value rate is flagged too. Model scores and labels can be checked the same way (es.drift_report({"score": ref_scores}, {"score": live_scores})).

    DriftReport dataclass

    Per-feature drift results. features rows carry the test, statistic, raw and Holm-adjusted p-values, PSI, a distance, missing-rate change and whether the feature drifted.

    drifted 

    drifted() -> list[str]

    Names of the drifted features, largest PSI first.

    drift_report 

    drift_report(reference: Any, current: Any, *, features: Optional[Sequence[str]] = None, categorical: Optional[Sequence[str]] = None, alpha: float = 0.05, psi_threshold: float = 0.1, distance_threshold: float = 0.1, bins: int = 10, eps: float = 0.0001) -> DriftReport

    Compare every shared feature of reference and current (see the module docstring). features selects and orders features (or names the columns of 2-D arrays); categorical forces features to be treated as categories (for example integer codes).

    evalsuite.forecasting

    Forecast evaluation: scaled errors, quantile and interval scores, CRPS, and the Diebold–Mariano test.

    import evalsuite as es es.mase(y_test, y_hat, y_train=y_train, m=12) # < 1: better than the seasonal naive forecast es.interval_score(y_test, lower, upper, level=0.9) # width plus penalties for misses es.crps(y_test, ensemble=samples) # or crps(y_test, mean=mu, sd=sigma) es.diebold_mariano(y_test, y_hat_a, y_hat_b, h=1) # are A's forecasts more accurate than B's? es.forecast_report(y_test, {"ets": a, "arima": b}, y_train=y_train, m=12)

    Definitions: MASE and RMSSE follow Hyndman & Koehler (2006) and the M5 competition, scaled by the in-sample (seasonal) naive forecast; the interval score and MSIS follow Gneiting & Raftery (2007) and the M4 competition; CRPS for ensembles uses the energy form (as properscoring) and for normal forecasts the closed form; the Diebold–Mariano (1995) test uses the Harvey, Leybourne & Newbold (1997) small-sample correction with a t reference distribution.

    ForecastReport dataclass

    Accuracy of several forecasts of one series, with Diebold–Mariano tests against a baseline.

    to_html 

    to_html(*, digits: int = 3) -> str

    The Markdown tables as an HTML fragment (escaped), e.g. for :func:evalsuite.html_report.

    mase 

    mase(y_true: Any, y_pred: Any, *, y_train: Any, m: int = 1) -> MetricResult

    Mean absolute scaled error: MAE divided by the in-sample MAE of the seasonal naive forecast with period m (1 for the plain random walk). Below 1 beats the naive forecast.

    rmsse 

    rmsse(y_true: Any, y_pred: Any, *, y_train: Any, m: int = 1) -> MetricResult

    Root mean squared scaled error (M5 competition): sqrt(MSE / in-sample MSE of the seasonal naive forecast).

    pinball_loss 

    pinball_loss(y_true: Any, quantile_preds: Any, *, quantiles: Any) -> MetricResult

    Mean pinball (quantile) loss. quantile_preds is n × q (one column per quantile in quantiles) or a vector for a single quantile. params["per_quantile"] holds each quantile's loss (as scikit-learn's mean_pinball_loss); the value is their mean.

    interval_score 

    interval_score(y_true: Any, lower: Any, upper: Any, *, level: float = 0.95) -> MetricResult

    Mean interval (Winkler) score of central level prediction intervals (Gneiting & Raftery 2007): width + (2/α)·(lower − y) when y < lower + (2/α)·(y − upper) when y > upper, α = 1 − level. Lower is better.

    msis 

    msis(y_true: Any, lower: Any, upper: Any, *, y_train: Any, m: int = 1, level: float = 0.95) -> MetricResult

    Mean scaled interval score (M4 competition): the interval score divided by the in-sample MAE of the seasonal naive forecast.

    interval_coverage 

    interval_coverage(y_true: Any, lower: Any, upper: Any, *, level: Optional[float] = None) -> MetricResult

    Share of observations inside their prediction intervals, with a Wilson interval; with the nominal level the binomial test of coverage = level is added (params["p_value"]).

    crps 

    crps(y_true: Any, *, ensemble: Any = None, mean: Any = None, sd: Any = None) -> MetricResult

    Mean continuous ranked probability score. Give ensemble (n × m sample paths / members) for the empirical CRPS E|X − y| − ½E|X − X'|, or mean and sd for normal forecasts (closed form). Lower is better; for a point forecast it reduces to the absolute error.

    diebold_mariano 

    diebold_mariano(y_true: Any, pred_a: Any, pred_b: Any, *, h: int = 1, loss: str = 'squared', alternative: str = 'two-sided', harvey: bool = True) -> MetricResult

    Diebold–Mariano test of equal predictive accuracy of two forecasts of the same series. loss is "squared" or "absolute"; h is the forecast horizon (the loss differential's autocorrelation is allowed up to lag h − 1). The value is the DM statistic (negative: A's losses are smaller); params holds the p-value and the mean loss difference. alternative="less" tests that A is more accurate.

    forecast_report 

    forecast_report(y_true: Any, forecasts: Mapping[str, Any], *, y_train: Any = None, m: int = 1, baseline: Optional[str] = None, h: int = 1, loss: str = 'squared') -> ForecastReport

    MAE, RMSE, sMAPE (and MASE with y_train) for each forecast, and a Holm-adjusted Diebold–Mariano test of each against baseline (the first forecast by default).

    evalsuite.multilabel

    Multi-label classification and ranked retrieval / recommendation reports, with confidence intervals.

    import evalsuite as es es.multilabel_report(Y_true, Y_pred, Y_score) # n × labels 0/1 matrices (+ scores for ranking metrics) es.ranking_report(qrels, {"bm25": run_a, "dense": run_b}, k=10)

    multilabel_report: subset accuracy, Hamming loss, micro / macro / sample-averaged precision, recall and F1, Jaccard, and with scores label-ranking average precision, coverage error, ranking loss and micro / macro ROC AUC (definitions as scikit-learn), each with a percentile bootstrap interval over examples, plus a per-label table.

    ranking_report: per-query nDCG@k, AP@k, reciprocal rank, precision@k and recall@k (trec_eval conventions: linear gains, log2 discount, AP and recall over all relevant documents in the judgements), averaged over queries with bootstrap intervals, and paired randomization tests (Smucker, Allan & Carterette 2007) of every system against a baseline with Holm adjustment.

    MultilabelReport dataclass

    Multi-label metrics with bootstrap intervals (metrics[name] = {value, low, high}) and per-label rows.

    to_html 

    to_html(*, digits: int = 3) -> str

    The Markdown tables as an HTML fragment (escaped), e.g. for :func:evalsuite.html_report.

    RankingReport dataclass

    Retrieval / recommendation metrics per system with intervals and tests against a baseline.

    to_html 

    to_html(*, digits: int = 3) -> str

    The Markdown tables as an HTML fragment (escaped), e.g. for :func:evalsuite.html_report.

    multilabel_report 

    multilabel_report(y_true: Any, y_pred: Any = None, y_score: Any = None, *, threshold: float = 0.5, labels: Optional[Sequence[str]] = None, level: float = 0.95, n_resamples: int = 1000, random_state: Optional[int] = None) -> MultilabelReport

    Multi-label evaluation (see the module docstring). Give y_pred (0/1), y_score (probabilities or scores; predictions are then y_score >= threshold unless y_pred is given), or both.

    ranking_report 

    ranking_report(qrels: Mapping[Any, Mapping[Any, float]], runs: Mapping[str, Mapping[Any, Any]], *, k: int = 10, baseline: Optional[str] = None, primary: str = 'ndcg', level: float = 0.95, n_resamples: int = 2000, n_permutations: int = 10000, random_state: Optional[int] = None) -> RankingReport

    Evaluate ranked runs against relevance judgements (see the module docstring).

    qrels maps query → {doc: relevance (0 = not relevant)}; each run maps query → ranked list of docs or {doc: score}. Queries in qrels with no relevant document are skipped; a query a run does not answer scores 0. primary (ndcg, ap, rr, precision, recall) is the measure tested against baseline (first run).
