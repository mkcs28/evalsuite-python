    Evaluate, compare, intervals

    evalsuite.api

    High-level API: evaluate().

    evaluate 

    evaluate(y_true: ArrayLike, y_pred: Optional[ArrayLike] = None, *, y_prob: Optional[ArrayLike] = None, task: Optional[str] = None, metrics: Optional[Sequence[str]] = None, average: Optional[str] = 'auto', labels: Optional[ArrayLike] = None, pos_label: Any = None, sample_weight: Optional[ArrayLike] = None, zero_division: ZeroDivision = 'warn', ci: Any = 'analytic', level: float = 0.95, baseline_pred: Optional[ArrayLike] = None, baseline_prob: Optional[ArrayLike] = None, n_resamples: int = 1000, random_state: Optional[int] = 0, clusters: Optional[ArrayLike] = None) -> EvaluationResult

    Evaluate predictions with a standard set of metrics (or the metrics you name), with confidence intervals and, given a baseline, paired significance tests against it.

    The task is inferred when omitted: probabilities or integer/string labels mean classification, non-integer numbers mean regression. Inputs are validated once and shared intermediate results (the confusion matrix) are computed once for all metrics.

    import evalsuite as es r = es.evaluate([0, 1, 1, 0], [0, 1, 0, 0]) round(r["accuracy"], 2) 0.75

    Intervals (level, 95% by default) are in each metric's params (ci_low, ci_high, ci_method) and in every summary and export. ci="analytic" (default, no extra cost) gives closed-form intervals where a standard one exists: Wilson for accuracy / precision / recall / specificity / NPV, DeLong for binary ROC AUC, Student-t for mean losses (Brier, log loss, MAE, MSE, RMSE, mean bias). ci="bootstrap" gives paired percentile-bootstrap intervals for every metric (n_resamples, seeded by random_state); ci=False turns them off. baseline_pred / baseline_prob (e.g. the current model) add the difference, its interval and a paired test per metric (McNemar for accuracy, DeLong for ROC AUC, paired bootstrap otherwise; Holm-adjusted), as baseline_* params and result.comparison. clusters (one id per observation, e.g. the patient of each scan or the document of each question) makes every interval and baseline test a cluster bootstrap that resamples whole clusters; ordinary intervals are too narrow when observations within a cluster are correlated.

    evalsuite.stats.intervals

    Confidence intervals: bootstrap (percentile, basic, BCa), Wilson and Clopper-Pearson, DeLong.

    resample_indices 

    resample_indices(n: int, n_resamples: int, rng: Generator, strata: Optional[NDArray[Any]] = None, resampling: str = 'numpy') -> NDArray[np.int64]

    (n_resamples, n) indices drawn with replacement, optionally within strata (keeps class balance).

    resampling="native" draws them in the compiled core (xoshiro256++, in parallel) from one seed taken from rng: reproducible for a given random_state and thread count–independent, but a different stream from NumPy's, so intervals differ (statistically equivalently) from the default.

    resampled_distributions 

    resampled_distributions(calls: list[MetricCall], n: int, n_resamples: int, rng: Generator, strata: Optional[NDArray[Any]], resampling: str) -> list[tuple[NDArray[np.float64], int]]

    :func:bootstrap_distribution of every call over the same :func:resample_indices (paired resamples). Plain NumPy resamples are drawn in chunks so memory stays bounded; the draws, and so every result, are identical to drawing them all at once.

    bootstrap_ci 

    bootstrap_ci(metric: Any, y_true: ArrayLike, y_pred: Optional[ArrayLike] = None, *, y_prob: Optional[ArrayLike] = None, sample_weight: Optional[ArrayLike] = None, level: float = 0.95, method: BootstrapMethod = 'bca', n_resamples: int = 2000, random_state: Optional[int] = None, stratify: Optional[bool] = None, jackknife_groups: int = 1000, resampling: str = 'numpy', clusters: Optional[ArrayLike] = None, **metric_kwargs: Any) -> ConfidenceInterval

    Bootstrap confidence interval for any metric.

    ``metric`` is a metric function (``es.f1``) or its name (``"f1"``). Pass ``y_pred`` for label/value
metrics or ``y_prob`` for probability metrics; extra keyword arguments go to the metric (for example
``average="macro"``). Resampling is stratified by class for classification targets unless
``stratify=False``, so every resample contains every class. For classification metrics that accept
``labels``, the full label set is fixed across resamples.

``method``: ``"bca"`` (bias-corrected and accelerated; default, Efron 1987), ``"percentile"`` or
``"basic"``. Set ``random_state`` for reproducible intervals. Resamples on which the metric is undefined
are counted in ``params["failed_resamples"]``; more than 10% raises :class:`StatisticalTestError`.

    resampling="native" (opt-in) draws the resample indices in the compiled core instead of NumPy: faster on large inputs and still reproducible with random_state, but a different random stream from the default.

    clusters (one id per observation: patient, document, site, conversation) resamples whole clusters instead of observations (cluster bootstrap; Field & Welsh 2007), so correlated observations in a cluster are kept together. Ordinary intervals are too narrow when observations are clustered; the cluster interval is honest. BCa's acceleration then uses leave-one-cluster-out estimates.

    References: Efron B. Better bootstrap confidence intervals. JASA. 1987;82(397):171-185.
Efron B, Tibshirani RJ. An Introduction to the Bootstrap. Chapman & Hall; 1993.

    cluster_distribution 

    cluster_distribution(call: MetricCall, members: list[NDArray[int64]], picks: list[NDArray[Any]]) -> tuple[NDArray[np.float64], int]

    Metric value on each cluster resample (picks[b] lists the drawn clusters), NaN where undefined.

    Equal to concatenating the drawn clusters' observations and calling the metric, but much faster: confusion-matrix metrics add up per-cluster code counts (one small matrix product for all resamples), and binary ROC AUC / average precision weight each observation by how often its cluster was drawn.

    proportion_ci 

    proportion_ci(successes: int, n: int, *, level: float = 0.95, method: Literal['wilson', 'clopper-pearson', 'normal'] = 'wilson') -> ConfidenceInterval

    Confidence interval for a proportion successes / n.

    "wilson" (default; good coverage even for small n or extreme proportions), "clopper-pearson" (exact, conservative) or "normal" (Wald; shown for comparison, not recommended).

    References: Wilson EB. JASA. 1927;22(158):209-212. Clopper CJ, Pearson ES. Biometrika. 1934;26(4):404-413. Brown LD, Cai TT, DasGupta A. Interval estimation for a binomial proportion. Stat Sci. 2001;16(2):101-133.

Biometrics. 1988;44(3):837-845. Sun X, Xu W. Fast implementation of DeLong's algorithm. IEEE Signal Process Lett. 2014;21(11):1389-1393.

    compare 

    compare(y_true: ArrayLike, predictions: Optional[Mapping[str, ArrayLike]] = None, *, probabilities: Optional[Mapping[str, ArrayLike]] = None, metrics: Optional[Sequence[str]] = None, baseline: Optional[str] = None, level: float = 0.95, alpha: float = 0.05, n_resamples: int = 1000, correction: str = 'holm', random_state: Optional[int] = None, stratify: Optional[bool] = None, sample_weight: Optional[ArrayLike] = None, metric_kwargs: Optional[Mapping[str, Mapping[str, Any]]] = None, resampling: str = 'numpy', _allow_single: bool = False) -> ComparisonResult

    Compare models evaluated on the same test set.

    predictions and/or probabilities map model names to that model's predicted labels/values or probabilities. Every model is resampled on the same bootstrap indices (paired), giving a percentile confidence interval per model and metric and a paired test per pair of models:

    • accuracy: McNemar's test (exact when there are fewer than 25 discordant pairs);
    • binary ROC AUC: DeLong's test;
    • everything else: paired bootstrap test.

    Pairs are every model against baseline if given, otherwise all pairs. p-values are adjusted within each metric (correction: "holm", "bonferroni", "hochberg", "bh", "by"); significant uses the adjusted p-value and alpha. metric_kwargs passes options per metric, e.g. {"f1": {"average": "macro"}}. resampling="native" (opt-in) draws the bootstrap indices in the compiled core; see :func:bootstrap_ci.

    mcnemar_test 

    mcnemar_test(y_true: ArrayLike, y_pred_a: ArrayLike, y_pred_b: ArrayLike, *, exact: Optional[bool] = None, correction: bool = True) -> TestResult

    McNemar's test: do two classifiers have the same error rate on the same observations?

    Uses only discordant pairs: b = A right & B wrong, c = A wrong & B right. exact=None (default) uses the exact binomial test when b + c < 25 and the chi-squared test otherwise (with Edwards' continuity correction unless correction=False). estimate is the accuracy difference A − B.

    References: McNemar Q. Psychometrika. 1947;12(2):153-157. Edwards AL. Psychometrika. 1948;13:185-187. Dietterich TG. Approximate statistical tests for comparing supervised classification learning algorithms. Neural Comput. 1998;10(7):1895-1923.

    delong_test 

    delong_test(y_true: ArrayLike, y_prob_a: ArrayLike, y_prob_b: ArrayLike, *, pos_label: Any = None, level: float = 0.95) -> TestResult

    DeLong's test for two correlated ROC AUCs (same observations, two models). estimate is AUC_A − AUC_B and ci its confidence interval.

    Reference: DeLong ER, DeLong DM, Clarke-Pearson DL. Biometrics. 1988;44(3):837-845.

    paired_bootstrap_test 

    paired_bootstrap_test(metric: Any, y_true: ArrayLike, y_pred_a: Optional[ArrayLike] = None, y_pred_b: Optional[ArrayLike] = None, *, y_prob_a: Optional[ArrayLike] = None, y_prob_b: Optional[ArrayLike] = None, sample_weight: Optional[ArrayLike] = None, n_resamples: int = 2000, level: float = 0.95, random_state: Optional[int] = None, stratify: Optional[bool] = None, alternative: Literal['two-sided', 'greater', 'less'] = 'two-sided', resampling: str = 'numpy', **metric_kwargs: Any) -> TestResult

    Paired bootstrap test for any metric: is metric(A) − metric(B) different from 0?

    Both models are evaluated on the same resampled observations. The p-value uses the shifted bootstrap distribution (difference re-centred on 0 under the null), with the +1 correction so it is never 0: p = (1 + #{|δ* − δ̂| ≥ |δ̂|}) / (B + 1) for a two-sided test. ci is the percentile interval of δ*.

    resampling="native" (opt-in) draws the resample indices in the compiled core; see :func:bootstrap_ci.

    Reference: Efron B, Tibshirani RJ. An Introduction to the Bootstrap. Chapman & Hall; 1993, ch. 16.

    evalsuite.stats.hypothesis

    Hypothesis tests for comparing scores, groups and categorical outcomes.

    Each test returns a :class:TestResult with the statistic, p-value, an effect size in estimate (named in params["effect_size"]) and, where standard, a confidence interval. SciPy is the reference: the common tests compute the same statistics directly (one ranking pass, closed-form tails, cached Shapiro–Wilk weights) and are tested to match SciPy, falling back to SciPy where it uses a different algorithm (exact permutation tests, older Shapiro–Wilk); EvalSuite adds input validation, effect sizes and consistent results.

    t_test 

    t_test(a: ArrayLike, b: ArrayLike, *, equal_var: bool = False, alternative: Alternative = 'two-sided', level: float = 0.95) -> TestResult

    Two-sample t-test for mean(a) − mean(b). Welch's test by default (equal_var=False), which does not assume equal variances; equal_var=True gives Student's test. estimate is the mean difference with a confidence interval; params["cohens_d"] is the standardised effect size.

    References: Welch BL. Biometrika. 1947;34(1-2):28-35. Student. Biometrika. 1908;6(1):1-25.

    paired_t_test 

    paired_t_test(a: ArrayLike, b: ArrayLike, *, alternative: Alternative = 'two-sided', level: float = 0.95) -> TestResult

    Paired t-test for the mean of a − b (for example per-fold scores of two models on the same folds). estimate is the mean difference with a confidence interval; params["cohens_dz"] is d_z.

    mann_whitney_test 

    mann_whitney_test(a: ArrayLike, b: ArrayLike, *, alternative: Alternative = 'two-sided') -> TestResult

    Mann–Whitney U (Wilcoxon rank-sum) test. statistic is U for a; estimate is the rank-biserial correlation r = 2U/(n₁n₂) − 1 (equal to Cliff's delta), and params["auc"] = U/(n₁n₂) = P(a > b) + ½P(a = b).

    References: Mann HB, Whitney DR. Ann Math Stat. 1947;18(1):50-60. Kerby DS. Compr Psychol. 2014;3:11.IT.3.1.

    wilcoxon_test 

    wilcoxon_test(a: ArrayLike, b: ArrayLike, *, alternative: Alternative = 'two-sided', zero_method: Literal['wilcox', 'pratt', 'zsplit'] = 'wilcox') -> TestResult

    Wilcoxon signed-rank test for paired samples (a − b). estimate is the matched-pairs rank-biserial correlation (T⁺ − T⁻) / (T⁺ + T⁻) over the non-zero differences.

    Reference: Wilcoxon F. Biometrics Bull. 1945;1(6):80-83.

    kruskal_wallis_test 

    kruskal_wallis_test(*groups: ArrayLike) -> TestResult

    Kruskal–Wallis H test: do two or more independent groups come from the same distribution? estimate is epsilon-squared, H / ((n² − 1)/(n + 1)).

    References: Kruskal WH, Wallis WA. JASA. 1952;47(260):583-621. Tomczak M, Tomczak E. Trends Sport Sci. 2014;1(21):19-25.

    friedman_test 

    friedman_test(*groups: ArrayLike) -> TestResult

    Friedman test for three or more related samples (for example several models scored on the same datasets or folds; each argument is one model's scores). estimate is Kendall's W = χ² / (n (k − 1)).

    References: Friedman M. JASA. 1937;32(200):675-701. Demšar J. Statistical comparisons of classifiers over multiple data sets. JMLR. 2006;7:1-30.

    shapiro_wilk_test 

    shapiro_wilk_test(x: ArrayLike) -> TestResult

    Shapiro–Wilk test of normality (3 ≤ n ≤ 5000 for an accurate p-value).

    Reference: Shapiro SS, Wilk MB. Biometrika. 1965;52(3-4):591-611.

    chi_square_test 

    chi_square_test(table: ArrayLike, *, correction: bool = True) -> TestResult

    Pearson's χ² test of independence for an r × c contingency table. Yates' continuity correction is applied to 2 × 2 tables unless correction=False. estimate is Cramér's V (from the uncorrected statistic, as in :func:cramers_v); params["expected"] holds the expected counts (the approximation is doubtful when many are below 5).

    Reference: Pearson K. Philos Mag. 1900;50(302):157-175. Cramér H. Mathematical Methods of Statistics. 1946.

    fisher_exact_test 

    fisher_exact_test(table: ArrayLike, *, alternative: Alternative = 'two-sided') -> TestResult

    Fisher's exact test for a 2 × 2 table. estimate is the sample odds ratio (a·d)/(b·c).

    Reference: Fisher RA. J R Stat Soc. 1922;85(1):87-94.

    evalsuite.stats.effect

    Effect sizes and multiple-comparison correction.

    cohens_d 

    cohens_d(a: ArrayLike, b: ArrayLike, *, paired: bool = False) -> float

    Cohen's d for mean(a) − mean(b).

    Independent samples: difference over the pooled standard deviation. paired=True: mean difference over the standard deviation of the differences (d_z), for per-fold or per-subject scores of two models.

    Reference: Cohen J. Statistical Power Analysis for the Behavioral Sciences. 2nd ed. Erlbaum; 1988. Lakens D. Calculating and reporting effect sizes. Front Psychol. 2013;4:863.

    hedges_g 

    hedges_g(a: ArrayLike, b: ArrayLike, *, paired: bool = False) -> float

    Hedges' g: Cohen's d with the exact small-sample bias correction J(df) = Γ(df/2) / (√(df/2) Γ((df−1)/2)).

    Reference: Hedges LV. Distribution theory for Glass's estimator of effect size and related estimators. J Educ Stat. 1981;6(2):107-128.

    cliffs_delta 

    cliffs_delta(a: ArrayLike, b: ArrayLike) -> float

    Cliff's delta: P(a > b) − P(a < b) over all pairs; a non-parametric effect size in [−1, 1].

    Computed in O((n + m) log m). Reference: Cliff N. Dominance statistics: ordinal analyses to answer ordinal questions. Psychol Bull. 1993;114(3):494-509.

    cramers_v 

    cramers_v(table: ArrayLike, *, bias_correction: bool = False) -> float

    Cramér's V for an r × c contingency table: √(χ² / (n · (min(r, c) − 1))), from the uncorrected Pearson χ². bias_correction=True applies Bergsma's correction, which reduces the upward bias in small samples.

    References: Cramér H. Mathematical Methods of Statistics. Princeton; 1946. Bergsma W. A bias-correction for Cramér's V and Tschuprow's T. J Korean Stat Soc. 2013;42(3):323-328.

    adjust_pvalues 

    adjust_pvalues(p_values: ArrayLike, *, method: Literal['bonferroni', 'holm', 'hochberg', 'bh', 'by'] = 'holm') -> NDArray[np.float64]

    Adjust p-values for multiple comparisons (same order as the input).

    "holm" (default; controls the family-wise error rate, uniformly more powerful than Bonferroni), "bonferroni", "hochberg" (step-up; controls the family-wise error rate under independence or positive dependence, more powerful than Holm), "bh" (Benjamini-Hochberg false discovery rate) or "by" (Benjamini-Yekutieli, FDR under arbitrary dependence).

    References: Holm S. Scand J Stat. 1979;6(2):65-70. Hochberg Y. Biometrika. 1988;75(4):800-802. Benjamini Y, Hochberg Y. J R Stat Soc B. 1995;57(1):289-300. Benjamini Y, Yekutieli D. Ann Stat. 2001;29(4):1165-1188.

    evalsuite.stats.planning

    Study planning: how many test items are needed for a given precision or to detect a given difference.

    • :func:sample_size_proportion — items so that a proportion (accuracy, sensitivity, ...) has a confidence interval no wider than ± half_width.
    • :func:sample_size_two_proportions — items to detect a difference between two models' accuracies, on the same items (paired, McNemar; Connor 1987) or on separate samples (Fleiss, Levin & Paik 2003).
    • :func:sample_size_auc — positives and negatives for an ROC AUC interval of given width, or to show an AUC above a reference value (Hanley & McNeil 1982; Obuchowski 1998).
    • :func:sample_size_mean_difference — pairs (or per-group observations) to detect a difference in a mean score or loss (paired or two-sample t approximation).
    • power_* counterparts give the power achieved with a fixed sample.

    All formulas are the standard normal-approximation ones and are documented with their references; sample sizes are rounded up.

    SampleSize dataclass

    A planned sample size with the assumptions behind it.

    sample_size_proportion 

    sample_size_proportion(p: float, half_width: float, *, level: float = 0.95) -> SampleSize

    Items so that a proportion near p is estimated within ± half_width (normal approximation, n = z² p (1 − p) / w²). Use p = 0.5 when nothing is known (the most conservative choice).

    sample_size_two_proportions 

    sample_size_two_proportions(p1: float, p2: float, *, alpha: float = 0.05, power: float = 0.8, paired: bool = True, discordance: Optional[float] = None, two_sided: bool = True) -> SampleSize

    Items needed to detect accuracy p1 vs p2.

    paired=True (default; both models answer the same items, McNemar's test, Connor 1987): n = (z_α √ψ + z_β √(ψ − δ²))² / δ², with ψ the share of items the models disagree on (discordance). Without discordance, ψ assumes independent errors, p1(1 − p2) + p2(1 − p1), which is conservative when the models are correlated (they usually are; a pilot estimate of ψ gives a smaller n). paired=False: two separate samples, n per group (Fleiss, Levin & Paik 2003).

    power_two_proportions 

    power_two_proportions(n: int, p1: float, p2: float, *, alpha: float = 0.05, paired: bool = True, discordance: Optional[float] = None, two_sided: bool = True) -> float

    Power to detect p1 vs p2 with n items (paired) or n per group (unpaired).

    sample_size_auc 

    sample_size_auc(auc: float, *, prevalence: float, half_width: Optional[float] = None, auc0: Optional[float] = None, level: float = 0.95, alpha: float = 0.05, power: float = 0.8) -> SampleSize

    Total items (positives + negatives at prevalence) for an ROC AUC near auc.

    Give half_width for an interval no wider than ± half_width, or auc0 to show that the AUC exceeds a reference value (one-sided, at alpha with power; variance under both hypotheses, Obuchowski 1998). Variances follow Hanley & McNeil (1982).

    power_auc 

    power_auc(n: int, auc: float, auc0: float, *, prevalence: float, alpha: float = 0.05) -> float

    Power of a one-sided test that the AUC exceeds auc0 with n items at prevalence.

    sample_size_mean_difference 

    sample_size_mean_difference(delta: float, sd: float, *, alpha: float = 0.05, power: float = 0.8, paired: bool = True, two_sided: bool = True) -> SampleSize

    Items to detect a difference delta in a mean score (a loss, a rating, a per-item metric).

    paired=True: sd is the standard deviation of the per-item differences; n = ((z_α + z_β) σ / δ)², refined with the t distribution. paired=False: sd is the per-group standard deviation; n per group = 2 ((z_α + z_β) σ / δ)², refined likewise.

    power_mean_difference 

    power_mean_difference(n: int, delta: float, sd: float, *, alpha: float = 0.05, paired: bool = True, two_sided: bool = True) -> float

    Power of a paired (or two-sample, n per group) t-test to detect delta (noncentral t).
