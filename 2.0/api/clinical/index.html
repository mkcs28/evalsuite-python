    Clinical and survival

    evalsuite.clinical

    Clinical evaluation: diagnostic accuracy measures with confidence intervals, and decision curve analysis.

    DecisionCurve dataclass

    Net benefit of one or more models, of treating everyone and of treating no one, per threshold.

    useful_range 

    useful_range(model: Optional[str] = None) -> list[tuple[float, float]]

    Threshold intervals where the model beats both treating everyone and treating no one.

    DiagnosticReport dataclass

    Every diagnostic accuracy measure for one binary test, each with a confidence interval.

    Index it by name: report["lr_positive"] is a :class:ConfidenceInterval. counts holds the 2×2 table (tp, fp, fn, tn).

    diagnostic_odds_ratio 

    diagnostic_odds_ratio(y_true: ArrayLike, y_pred: ArrayLike, *, pos_label: Any = None, sample_weight: Optional[ArrayLike] = None, correction: float = 0.0) -> MetricResult

    Diagnostic odds ratio. correction=0.5 adds 0.5 to every cell when any cell is zero (Haldane–Anscombe), which keeps the estimate finite; the default 0 reports inf or NaN with a warning instead.

    lr_negative 

    lr_negative(y_true: ArrayLike, y_pred: ArrayLike, *, pos_label: Any = None, sample_weight: Optional[ArrayLike] = None) -> MetricResult

    Negative likelihood ratio. inf (with a warning) when specificity is 0 and sensitivity < 1.

    lr_positive 

    lr_positive(y_true: ArrayLike, y_pred: ArrayLike, *, pos_label: Any = None, sample_weight: Optional[ArrayLike] = None) -> MetricResult

    Positive likelihood ratio. inf (with a warning) when specificity is 1 and sensitivity > 0.

    net_benefit 

    net_benefit(y_true: ArrayLike, y_prob: ArrayLike, *, threshold: float, pos_label: Any = None, sample_weight: Optional[ArrayLike] = None) -> MetricResult

    Net benefit at one threshold probability (treat when predicted risk ≥ threshold).

    ppv 

    ppv(y_true: ArrayLike, y_pred: ArrayLike, *, pos_label: Any = None, sample_weight: Optional[ArrayLike] = None, zero_division: ZeroDivision = 'warn') -> MetricResult

    Positive predictive value (precision of the positive class).

    sensitivity 

    sensitivity(y_true: ArrayLike, y_pred: ArrayLike, *, pos_label: Any = None, sample_weight: Optional[ArrayLike] = None, zero_division: ZeroDivision = 'warn') -> MetricResult

    Sensitivity (recall of the positive class).

    youden_j 

    youden_j(y_true: ArrayLike, y_pred: ArrayLike, *, pos_label: Any = None, sample_weight: Optional[ArrayLike] = None) -> MetricResult

    Youden's J statistic (informedness) for a binary test.

    decision_curve 

    decision_curve(y_true: ArrayLike, y_prob: Any, *, thresholds: Optional[ArrayLike] = None, pos_label: Any = None, sample_weight: Optional[ArrayLike] = None) -> DecisionCurve

    Decision curve analysis (Vickers & Elkin 2006).

    y_prob is one array of predicted risks, or a dict {"model name": risks} to compare models. thresholds defaults to 0.01, 0.02, …, 0.99. Treat-all net benefit is prevalence − (1 − prevalence) · pₜ / (1 − pₜ); treat-none is 0.

    diagnostic_report 

    diagnostic_report(y_true: ArrayLike, y_pred: ArrayLike, *, pos_label: Any = None, level: float = 0.95, proportion_method: str = 'wilson') -> DiagnosticReport

    Sensitivity, specificity, PPV, NPV, likelihood ratios, diagnostic odds ratio, Youden's J, accuracy and prevalence for a binary test, each with a confidence interval.

    Intervals: proportions use proportion_method (Wilson by default, or "clopper-pearson"); likelihood ratios use the log method of Simel et al. (1991); the diagnostic odds ratio uses Woolf's log method with 0.5 added to every cell when one is zero; Youden's J uses the Wald interval from the independent sensitivity and specificity variances, clipped to [−1, 1].

    evalsuite.survival

    Time-to-event (survival) evaluation with right-censored data.

    • :func:concordance_index — Harrell's C (ipcw=False) or Uno's IPCW C (ipcw=True), with a bootstrap interval on request.
    • :func:time_dependent_auc — cumulative/dynamic ROC AUC at each time point (Uno et al. 2007; Hung & Chiang 2010), and its mean over time.
    • :func:brier_score_survival / :func:integrated_brier_score — Graf et al. (1999) IPCW Brier score at each time point and integrated over a time range.
    • :func:kaplan_meier — the Kaplan–Meier estimate (and of the censoring distribution, reverse=True).

    Conventions follow scikit-survival, and the results agree with it (tests in tests/test_survival.py): event is True / 1 for an observed event and False / 0 for censoring; risk is a risk score (higher means earlier events); survival-probability estimate columns correspond to times. Inverse-probability-of- censoring weights come from the Kaplan–Meier estimate of the censoring distribution fitted on train_time / train_event (default: the evaluation data).

    SurvivalCurve dataclass

    A step function: prob[k] holds from time[k] until the next time point.

    kaplan_meier 

    kaplan_meier(time: Any, event: Any, *, reverse: bool = False) -> SurvivalCurve

    Kaplan–Meier survival curve; reverse=True estimates the censoring distribution G(t) (at tied times, events leave the risk set before censorings, as in scikit-survival).

    concordance_index 

    concordance_index(time: Any, event: Any, risk: Any, *, ipcw: bool = False, tau: Optional[float] = None, train_time: Any = None, train_event: Any = None, tied_tol: float = 1e-08, ci: Optional[str] = None, level: float = 0.95, n_resamples: int = 1000, random_state: Optional[int] = 0) -> MetricResult

    Concordance index for risk scores: the share of comparable pairs whose higher-risk member fails first (ties in risk count 1/2). ipcw=False: Harrell's C. ipcw=True: Uno's C, pairs weighted by 1 / G(t_i)² (censoring KM from train_*), optionally truncated at tau. ci="bootstrap" adds a percentile interval over resampled subjects.

    time_dependent_auc 

    time_dependent_auc(time: Any, event: Any, risk: Any, times: Any, *, train_time: Any = None, train_event: Any = None, tied_tol: float = 1e-08) -> MetricResult

    Cumulative/dynamic AUC at each of times: how well the risk scores separate subjects with an event by time t (cases, IPCW-weighted) from those still event-free after t (controls). risk is one score per subject or one column per time point. value is the mean AUC weighted by the Kaplan–Meier drop over the times; params["auc"] the per-time values.

    brier_score_survival 

    brier_score_survival(time: Any, event: Any, estimate: Any, times: Any, *, train_time: Any = None, train_event: Any = None) -> MetricResult

    IPCW Brier score (Graf et al. 1999) of predicted survival probabilities estimate[:, k] = P(T > times[k]) at each time point; value is the mean over times, params["brier"] the per-time values.

    integrated_brier_score 

    integrated_brier_score(time: Any, event: Any, estimate: Any, times: Any, *, train_time: Any = None, train_event: Any = None) -> MetricResult

    Integrated Brier score: the IPCW Brier score integrated over times (trapezoidal rule) and divided by the time range. Needs at least two time points. Lower is better; 0.25 is the score of predicting 0.5.

    evalsuite.reclassification

    Clinical model updates: does a new risk model reclassify patients better, and does a model transport to a new site?

    import evalsuite as es es.reclassification(y, p_old, p_new, cutoffs=[0.05, 0.2]) # NRI (categorical and continuous) and IDI es.external_validation(y_dev, p_dev, y_ext, p_ext) # development vs external site, and recalibration

    Net reclassification improvement (Pencina et al., Stat Med 2008): among events, the share moved to a higher risk category minus the share moved lower; among non-events, the share moved lower minus higher; the NRI is their sum. The continuous (category-free) NRI counts any increase or decrease (Pencina et al. 2011). The integrated discrimination improvement (IDI) is the gain in mean predicted risk among events minus that among non-events. P-values use Pencina's asymptotic z tests; intervals are percentile bootstrap (paired, stratified by outcome).

    external_validation reports discrimination (DeLong CIs and the unpaired difference), calibration-in-the-large, calibration slope, observed / expected ratio and Brier score at both sites, and how much intercept-only and logistic recalibration on the external data would recover (Steyerberg, Clinical Prediction Models, ch. 19).

    ReclassificationResult dataclass

    NRI (categorical and continuous) and IDI with p-values and bootstrap intervals.

    ExternalValidation dataclass

    Performance at the development and the external site, and what recalibration would recover.

    reclassification 

    reclassification(y: Any, p_old: Any, p_new: Any, *, cutoffs: Optional[Sequence[float]] = None, level: float = 0.95, n_resamples: int = 1000, random_state: Optional[int] = None) -> ReclassificationResult

    NRI and IDI of a new risk model against an old one on the same patients (see the module docstring). cutoffs (e.g. [0.05, 0.2]) define risk categories for the categorical NRI and the reclassification tables; the continuous NRI and the IDI are always reported.

    external_validation 

    external_validation(y_dev: Any, p_dev: Any, y_ext: Any, p_ext: Any, *, level: float = 0.95) -> ExternalValidation

    Compare a model's performance at development and at an external site (see the module docstring).

    evalsuite.cards

    Reporting standards: the evaluation sections that journals and model cards ask for, generated from data.

    report_card(y_true, y_prob, standard="tripod-ai") computes what TRIPOD+AI (Collins et al., BMJ 2024) asks a prediction-model paper to report about performance (sample size and outcome events; discrimination; calibration in the large, slope and plot-free summaries; classification at a threshold; clinical utility by net benefit; performance in subgroups) with confidence intervals, writes it up as a results paragraph and a table, and lists which checklist items are covered and which need your own text. standard="stard" (STARD 2015, diagnostic accuracy studies) and standard="consort-ai" (CONSORT-AI, trials of AI interventions) fill in those checklists' results items the same way. standard="model-card" produces the sections of a model card (Mitchell et al., FAT* 2019) with the quantitative analyses filled in and the narrative sections taken from context.

    Export with to_markdown(), to_latex(), to_html() or to_docx(path) (python-docx).

    ReportCard dataclass

    Computed performance results plus the text of a reporting-standard section.

    paragraph 

    paragraph(*, digits: int = 3) -> str

    A results paragraph in the style of a methods/results section.

    to_docx 

    to_docx(path: str, *, digits: int = 3) -> None

    Write a Word document with the paragraph, the table and (model card) the narrative sections.

    report_card 

    report_card(y_true: Any, y_prob: Any, *, y_pred: Any = None, standard: str = 'tripod-ai', threshold: float = 0.5, groups: Optional[Sequence[Any]] = None, group_name: str = 'subgroup', context: Optional[Mapping[str, str]] = None, pos_label: Any = None, level: float = 0.95, n_resamples: int = 1000, random_state: Optional[int] = 0) -> ReportCard

    Performance section for a reporting standard ("tripod-ai", "stard" for diagnostic accuracy studies, "consort-ai" for trials of AI interventions, or "model-card") from a binary outcome and predicted risks. groups adds a subgroup (fairness) table; context supplies the narrative sections of a model card (keys: model_details, intended_use, factors, metrics, evaluation_data, training_data, ethical_considerations, caveats). Intervals: DeLong for ROC AUC, Wilson for proportions, bootstrap (seeded) for calibration and the Brier score.

    evalsuite.fairness

    Fairness: performance by group, gaps between groups with confidence intervals, and corrected tests.

    fairness_report(y_true, y_pred, y_prob, groups=...) reports, for every group (and every intersection of several attributes), the selection rate, true and false positive rates, positive predictive value and accuracy (Wilson intervals), plus ROC AUC (DeLong) and calibration-in-the-large with probabilities. It then gives the standard gap measures with bootstrap intervals that resample within each group:

    • demographic parity difference (max − min selection rate) and ratio (min / max, the "four-fifths rule"),
    • equalized odds difference (the larger of the TPR and FPR gaps; Hardt et al. 2016),
    • equal opportunity difference (TPR gap) and predictive parity difference (PPV gap),

    and tests every group against a reference group (Fisher's exact test per metric, Holm-adjusted across all tests). Groups smaller than min_group_size are listed but not tested. The gap definitions match Fairlearn's.

    FairnessReport dataclass

    Per-group metrics, gap measures and tests (see :func:fairness_report).

    fairness_report 

    fairness_report(y_true: Any, y_pred: Any = None, y_prob: Any = None, *, groups: Union[Mapping[str, Any], Sequence[Any], ndarray], pos_label: Any = 1, threshold: float = 0.5, reference: Optional[str] = None, intersectional: bool = True, min_group_size: int = 10, level: float = 0.95, alpha: float = 0.05, n_resamples: int = 1000, random_state: Optional[int] = 0) -> FairnessReport

    Group fairness of a binary classifier.

    groups: one protected-attribute value per observation, or a mapping of attribute name → values (several attributes are crossed into intersectional groups such as sex=F & age=65+; with intersectional=False each attribute is analysed on its own and the reports' groups are listed per attribute). y_pred gives labels; with only y_prob labels are y_prob >= threshold. reference: the group the others are tested against (default: the largest).
